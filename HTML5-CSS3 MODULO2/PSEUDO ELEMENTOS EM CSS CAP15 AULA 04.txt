Pseudoclasse --> São palavras que definem estados de elementos dentro da HTML.


PSUDELEMENTO 

O Pseudelemento ele pode agir nas classes, nos elementos nos ID, ele mexem no conteúdo periférico do elemento. 

EX:
Se eu quiser que todo link no final tenha uma indicação que é um link:

                   a::after {
                              content: "[link]";
                              text-decoration: none;
                              font-weight: normal;
                              color: darkgray;
                             }

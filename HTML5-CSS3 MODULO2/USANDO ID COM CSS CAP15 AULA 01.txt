Digamos que você queira uma formatação diferente para o seu H1, na CSS quando você formata um H1, todos os h1 ficaram iguais, então para diferenciar um dos outros segue o seguinte. 

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Seletore Personalizados</title>
    <link rel="stylesheet" href="style.css"> --------------------------------------> ESSE LINK VOCÊ CRIA PARA CRIAR A PÁGINA DA CSS
</head>
<body>
    <h1>Criando sites com HTML e CSS</h1>
    <h1>Aprendendo HTML</h1>

PARA DIFERENCIAR O H1 você coloca um identificador que nesse exemplo foi chamado de principal 

<body>
    <h1 id="principal">Criando sites com HTML e CSS</h1>
    <h1>Aprendendo HTML</h1>

Pseudoclasse chamada root: 

Todo documento tem, é a raiz da arvore, tudo que for colocado nele vai servir para o documento inteiro.

Todas variáveis devem começar com dois traços --  e depois o nome da variável.

 :root {
    --cor0: #c5ebd6;
    --cor1: #83e1ad;
    --cor2: #3ddc84;
    --cor3: #2fa866;
    --cor4: #1a5c37;
    --cor5: #063d1e;
 }

Quando você for por as cores, você aperta CTRL+ESPAÇO E ROLA AS CORES ATÉ O FINAL, E LÁ VAI ESTAR AS CORES QUE VOCÊ ESCOLHEU.

 EX:

body {
    background-color:var(--cor0);


header > h1 {
    color: var(--cor3);
}

main h1 {
    color: var(--cor5);
}

@charsetchar "UTF-8"; 

@import url('https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Work+Sans:ital,wght@0,100..900;1,100..900&display=swap');

@font-face {

Escreve o nome  no fonte-family --> Depois SRC: URL DIGITA / E CTRL+ESPAÇO QUE APARECE A PASTA COM A FONTE E CLICA NELA.

Para a fonte, depois de por dentro do root você vai no lugar que você quer a fonte posta lá, digita ctrl+espaço que aparece o nome e pronto.

EXEMPLO:

    --cor0: #c5ebd6;
    --cor1: #83e1ad;
    --cor2: #3ddc84;
    --cor3: #2fa866;

    --fonte-destaque: "Bebas Neue", cursive; 
    --fonte-android: "Android, cursive";

 }

Configurações globais onde nenhum bloco, nenhum elemento vai ter margem em cima e margem em baixo. 

Eu quero selecionar todos os elementos de HTML e tirar as MARGINS e os PADDING.

COMO EU FAÇO PARA SELECIONAR TODOS OS ELEMENTOS: 

Você cria um seletor global que é o * e ele vale para todos os elementos.

 * {
    margin: 0px;
    padding: 0px;
 }

Outra coisa todo o conteúdo tá ocupando a largura inteira, isso facilita pra ver no celular, mas no computador as imagens ficam vazando para o lado, isso se chama responsividade, vai ser visto mais pra frente.
